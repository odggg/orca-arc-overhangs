    1

    Enable the pipeline

    Select Arc Overhang in Orca's process pipeline settings. Enabling this switch alone does not select the pipeline for your preset.

    2

    Slice your model

    Only suitable unsupported Bridge regions are replaced. If Orca uses extra overhang walls instead of bridges, that area stays unchanged.

    3

    Inspect the Arcs

    Open the Arc Overhang tab to inspect the generated support. Choose a region to see its layer and tool.

    When no support appearsWhat to check

    Check that the pipeline is selected and that the sliced model includes unsupported Bridge or Internal Bridge paths. A supported bridge above infill is intentionally retained.

    The default minimum area is 50 mm². Small, unanchored or insufficiently covered regions remain as sliced. Read the preview's skipped reasons on Overview.

    For counterbore models, partially bridged strips may already be supported. Check Orca's counterbore setting if you expected a different result.
