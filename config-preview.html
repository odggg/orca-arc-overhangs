Arc Overhang

Concentric arc toolpaths for flat overhangs. Applied during G-code export.

Inner wall overlap is the distance the Arc region can extend into printed walls. Larger values can reach inner wall lines. Arc spacing is independent: 0.5 with a 0.4 mm nozzle gives 0.2 mm spacing.

Import a WaveOverhangs profile

Take the values from a waveoverhangs.com/gallery entry (open a model, then copy from the page) or from the G-code you sliced with WaveOverhangs.

  • Usable: the "View Orca config block" text (lines like ; wave_overhang_line_spacing = 0.35), the "View WaveOverhangs debug header" text (the WAVE_OVERHANG_CONFIG line), or a profile JSON containing wave_overhang_* keys. Paste the whole block; only the wave settings are picked up.
  • Ignored: everything else (printer, filament, speeds of normal features, walls, infill). Set those in Orca as usual. Wave settings with no plugin equivalent are listed after importing.

Import fills in the fields below and switches the mode to Wave. Press Save settings to keep them.


Arc mode

Wave mode

Order of the wave lines. Smart follows the wavefront, Zigzag joins neighbouring lines into one path (helps against curling at line ends), Monotonic prints every line separately. (WaveOverhangs: wave_overhang_pattern)
Distance between neighbouring wave lines. 0.35 mm is the usual value for a 0.4 mm nozzle. (WaveOverhangs: wave_overhang_line_spacing)
Plastic pushed out per mm of wave line (an absolute volume, not a multiplier). (WaveOverhangs: wave_overhang_flow_mm3_per_mm)
Print speed of the wave lines. Very slow on purpose so each line cools in the air. (WaveOverhangs: wave_overhang_print_speed)
Speed of moves between wave lines. (WaveOverhangs: wave_overhang_travel_speed)
Speed of the walls on the layer that has waves. 0 keeps the slicer's wall speed. (WaveOverhangs: wave_overhang_perimeter_speed)
How far the waves reach under the wall so the wall bonds to them. Raise it if the wall comes loose from the waves. (WaveOverhangs: wave_overhang_perimeter_overlap)
Necks narrower than this split the wave region so the wavefront does not pinch shut. (WaveOverhangs: wave_overhang_minimum_width)
Stop adding wave lines once a new line would cover less than this area. (WaveOverhangs: wave_overhang_min_new_area)
Overhangs with a shorter outline stay normal bridges. 0 = off. (WaveOverhangs: wave_overhang_min_length)
Most wave lines grown per overhang region. 0 = no limit. (WaveOverhangs: wave_overhang_max_iterations)
On: every overhang found gets waves. Off: spans a normal bridge can handle (anchored on both sides, mostly convex) keep Orca's bridge. (WaveOverhangs: wave_overhang_instead_of_bridges)
Add denser lines near sharp overhang corners, which curl first. (WaveOverhangs: wave_overhang_corner_taper_enable)
Line spacing used near corners (smaller than the normal wave line spacing). (WaveOverhangs: wave_overhang_line_spacing_corner)
How far from a corner the denser lines reach. (WaveOverhangs: wave_overhang_corner_taper_distance)
Corners sharper than this angle get the reinforcement. (WaveOverhangs: wave_overhang_corner_angle_threshold)
Force the part fan to the speed below while printing waves; the previous fan speed is restored afterwards.
Part fan speed while printing waves. (WaveOverhangs: wave_overhang_fan_speed)
Nozzle temperature while printing waves, restored afterwards. 0 = leave unchanged. (WaveOverhangs: wave_overhang_nozzle_temp)
Pause after the waves so they get at least this much cooling time. 0 = off. (WaveOverhangs: wave_overhang_min_wave_time)
Pause at the end of a layer with waves so the whole layer takes at least this long. 0 = off. (WaveOverhangs: wave_overhang_min_layer_time)
Retraction before each jump between wave lines. 0 = use the general Retraction setting. (WaveOverhangs: wave_overhang_end_retract_length)

Wave floor (layers above the waves)

Number of layers above the waves that get the floor settings below. Orca decides how many of them are solid; this only changes how they print. (WaveOverhangs: wave_overhang_floor_layers)
Speed of solid infill on the floor layers. 0 = unchanged. (WaveOverhangs: wave_overhang_floor_print_speed)
Speed of walls on the floor layers. 0 = unchanged. (WaveOverhangs: wave_overhang_floor_perimeter_speed)
Floor layers over which the two floor speeds ramp back up to normal. 0 = no ramp. (WaveOverhangs: wave_overhang_floor_speed_ramp)
Print the solid floor above waves as a Hilbert curve, which warps less. (WaveOverhangs: wave_overhang_floor_use_hilbert)
How many of the floor layers use Hilbert. 0 = all of them. (WaveOverhangs: wave_overhang_floor_hilbert_layers)
Fill density of the Hilbert floor. 100 = solid. (WaveOverhangs: wave_overhang_floor_hilbert_density)
Force the part fan on the Hilbert floor layers (a low fan keeps them warm and reduces curl).
Part fan speed on the Hilbert floor layers. (WaveOverhangs: wave_overhang_floor_fan_speed)
Force the auxiliary fan (M106 P2) on the Hilbert floor layers.
Auxiliary fan speed on the Hilbert floor layers. (WaveOverhangs: wave_overhang_floor_aux_fan_speed)

Both modes

Lift the nozzle by this much for jumps between arcs or waves. 0 = off.
